About VaultDiary

VaultDiary is a private, encrypted diary application built for CSE447: Cryptography and Cryptanalysis. It was developed by forking Simple-Blog-w-Flask, an open-source Flask blog project. Me and my teammates have substantially modified it into a secure journaling platform.

On top of the original login, registration, and post-management foundation, this project adds from-scratch asymmetric encryption (RSA and ECC), custom salted password hashing, HMAC-based two-factor authentication, a key management and rotation system, HMAC data integrity verification, role-based access control, and fully self-issued session management.
